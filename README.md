# AlgeriaFireDetect

A Flask web app that predicts the Fire Weather Index (FWI) for the Algerian forest-fires dataset using a Ridge regression model, with notebooks for EDA, feature engineering and model comparison.

## Problem
The Algerian Forest Fires dataset (two regions, June-September 2012, 243 cleaned rows) records weather and fire-weather-system indices. The goal is to predict the continuous FWI value from weather readings.

## Approach (from `notebooks/`)
- `2.0-EDA And FE Algerian Forest Fires.ipynb`: exploration and feature engineering on the cleaned dataset.
- `3.0-Model Training.ipynb`: drops date columns, encodes `Classes` (fire / not fire -> 1/0), splits 75/25 (`random_state=42`), removes features correlated above 0.85 (BUI, DC), standardises with `StandardScaler`, then compares models on the test set:

| Model | MAE | R2 |
|---|---|---|
| Linear Regression | 0.547 | 0.985 |
| Lasso | 1.133 | 0.949 |
| LassoCV | 0.620 | 0.982 |
| Ridge / RidgeCV | 0.564 | 0.984 |
| ElasticNet | 1.882 | 0.875 |
| ElasticNetCV | 0.658 | 0.981 |

RidgeCV and the scaler were pickled to `models/ridge.pkl` and `models/scaler.pkl` and are used by the app.

## The app
`application.py` loads both pickles and serves:
- `/` - welcome page
- `/predictdata` - form (Temperature, RH, Ws, Rain, FFMC, DMC, ISI, Classes, Region) that returns the predicted FWI

## Deployment
`.github/workflows/main_fireml.yml` builds on Python 3.8 and deploys to an Azure Web App named `fireML` on pushes to `main` (the workflow was generated by Azure's deployment wizard; deploy credentials are referenced as GitHub secrets, none stored in the repo).

## Tech stack
Python, Flask, pandas, NumPy, scikit-learn, seaborn/matplotlib (notebooks), GitHub Actions, Azure App Service.

## Setup
```bash
pip install -r requirements.txt     # Flask, numpy, pandas, scikit-learn
python application.py               # serves on 0.0.0.0, Flask default port 5000
```

## Structure


## Limitations
- Tiny dataset (243 rows); high R2 is expected because FWI is derived from the input indices (FFMC, DMC, ISI), so the model largely re-learns a formula.
- Basic UI (plain form, no validation); `Classes`/`Region` must be entered as 0/1 numbers.
